# 从外部访问华为云PostgreSQL数据库的解决方案

## 问题说明
当前配置文件中使用的IP地址 172.16.0.99 是华为云VPC内部的私有IP地址，从公网无法直接访问。
这就是为什么即使配置了安全组规则允许您的公网IP访问，连接仍然失败。

## 解决方案

### 1. 使用RDS公网访问地址（推荐）
- 登录华为云控制台，找到您的PostgreSQL数据库实例
- 开启"公网访问"功能
- 系统会分配一个公网访问地址
- 修改配置文件中的host，使用分配的公网地址
- 确保安全组允许您的公网IP访问5432端口

### 2. 使用VPN或云专线
- 建立一个从您的网络到华为云VPC的安全连接
- 这样可以直接访问内部IP地址（172.16.0.99）
- 适合需要大量访问云上资源的企业

### 3. 通过跳板机访问
- 在华为云上创建一个具有公网IP的ECS实例
- 配置这个实例可以访问内部数据库
- 从本地通过SSH隧道连接到跳板机，再访问数据库
- SSH隧道示例：
  ```
  ssh -L 5432:172.16.0.99:5432 user@跳板机公网IP
  ```
- 然后将本地连接配置为连接到 localhost:5432

### 4. 使用华为云数据库代理服务
- 华为云提供了数据库代理服务，可以安全地暴露内部数据库
- 这提供了额外的安全性和连接池管理

## 修改配置文件
获取到正确的连接信息后，修改 config/db_config.yaml 文件中的PostgreSQL配置：

```yaml
postgresql:
  test:
    host: "获取到的公网访问地址"  # 例如: postgres-xxx.rds.huaweicloud.com
    port: 5432  # 公网访问端口，可能与内部端口不同
    user: "duoo"
    password: "Duoo@melot2023"
    database: "duoo"
    sslmode: "require"  # 公网访问建议启用SSL
```

## 测试连接
修改配置后，运行测试脚本验证连接：
```
python test_postgres_connection.py
```

## 注意事项
1. 使用公网访问数据库时，建议启用SSL连接（sslmode: "require"）
2. 定期检查和更新安全组规则，只允许必要的IP访问
3. 使用强密码，并考虑启用数据库的访问控制策略
4. 监控数据库连接和查询性能，公网访问可能比内部访问慢
