我想要写一个脚本 访客用户登录进app然后 申请某个家族的家族房，对应的家族长通过申请，可以批量让用户申请家族家族
脚本需要我来传多少个访客去申请，对应的家族长id
第一步：
访客用户登录
/api/user/v1/user/login   这是接口  post请求
这是传参
{"bizId":6,"channel":"guest","token":"019bd970-7376-7e6a-832d-39512df66c38","phoneCode":null,"smsCode":null,"password":null,"installReferrer":null,"inviteCode":null,"limitedUseAppCheckToken":null,"anchorId":0,"shareId":0}
里面的token需要随机传，拿到自己的id记录一下后面家族长同意申请需要
第二步
这个用户去申请家族房
/api/live/v1/tribe/room/member/apply  这是接口 post请求
tribeId    number    必填  家族id
apply    number     必填  1:join申请加入 2:leave申请离开 3:取消加入家族  
这是需求传的参数
第三步：
对应的家族长去同意申请 
/api/live/v1/tribe/room/member/approve  post请求
uid    number    必填 用户id
status    number    必填  1：审核通过、2：审核不通过、3:同意退会、4：拒绝退会、5：踢出家族
这是传参
